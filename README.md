# HRM

A professional, subscription-based Human Resource Management platform built from scratch for SaaS and self-hosted enterprise deployments.

## Product Model

HRM supports two primary deployment models:

- Cloud SaaS
- Customer-hosted / self-hosted enterprise

Both models use the same core product and require a valid time-bound software license.

## Commercial Model

Licenses are issued for:

- 6 months
- 1 year

Licenses control product entitlements, usage limits, deployment rights, and expiration. Customers renew their license to continue using the product.

Self-hosted customers may use their own:

- Server infrastructure
- PostgreSQL database
- Object storage
- SMTP/email provider
- AI provider

A valid HRM license remains required regardless of deployment location.
